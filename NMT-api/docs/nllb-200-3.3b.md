# NLLB-200 3.3B ONNX

## Artefacts attendus

Le modèle `facebook/nllb-200-3.3B` doit être fourni comme artefact externe. Il ne doit pas être commité dans Git.

Emplacement local recommandé pour lancer l'API en développement :

```text
NMT-api/
  Models/
    Nllb/
      nllb-200-3.3b.onnx
      tokenizer.json
```

Le fichier `tokenizer.json` doit provenir du même modèle Hugging Face que l'export ONNX. Le modèle et le tokenizer doivent être versionnés ensemble côté artefact.

## Configuration

Exemple `appsettings.json` :

```json
"NllbOnnx": {
  "ModelPath": "Models/Nllb/nllb-200-3.3b.onnx",
  "TokenizerPath": "Models/Nllb/tokenizer.json",
  "ModelRequired": true,
  "MaxNewTokens": 512,
  "EosTokenId": 2,
  "DecodingMode": "Greedy",
  "NumBeams": 1,
  "LengthPenalty": 1.0,
  "NoRepeatNgramSize": 0,
  "RepetitionPenalty": 1.0
}
```

`ModelRequired=true` est recommandé en production : l'application échoue au démarrage si le modèle ou le tokenizer est absent ou incompatible.

`ModelRequired=false` peut être utile pour démarrer l'API sans modèle en environnement de développement. Dans ce cas, les endpoints de traduction retournent `503` tant que les artefacts ne sont pas disponibles.

## Exemple SRT

1. Demander un token cookie :

```http
POST /api/auth/token
```

2. Envoyer un fichier SRT :

```http
POST /api/translations/jobs/srt
Content-Type: multipart/form-data

file=@subtitle.srt
sourceLanguage=fr
targetLanguage=en
maxNewTokens=512
```

3. Suivre le job :

```http
GET /api/translations/jobs/{jobId}
```

4. Télécharger le résultat :

```http
GET /api/translations/jobs/{jobId}/result
```

## Décodage

`DecodingMode=Greedy` est actuellement implémenté.

`DecodingMode=BeamSearch` est préparé dans la configuration, mais n'est pas encore implémenté dans le runner ONNX. Si cette valeur est configurée aujourd'hui, l'API retourne une erreur explicite indiquant que le beam search doit encore être ajouté.

## Politique Git

Les artefacts modèle ne doivent jamais être commités :

- `.onnx`
- `.bin`
- `.safetensors`
- `.pt`
- `.pth`
- `tokenizer.json`
- fichiers de poids ou exports associés

Le `.gitignore` du repository les exclut. Le `.csproj` exclut aussi `Models/**` du build et du publish pour éviter d'embarquer accidentellement les artefacts.
